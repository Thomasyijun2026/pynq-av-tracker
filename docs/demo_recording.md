# 实机演示内容

已提交成片为《基于PYNQ-Z2的声源定位与视觉跟随系统_作品演示.mp4》，采用 MP4 / H.264、1280 × 720、30 fps，时长 2 分 56.7 秒，文件大小 52.27 MB。文件身份见[提交材料索引](submitted_materials.md)。

## 画面中的功能流程

1. **硬件介绍**：展示四麦阵列、PYNQ-Z2 开发板、USB 相机与旋转支架。
2. **连接与服务就绪**：展示桌面控制台与板子的连接状态，以及人工初始化入口。
3. **初始化**：电脑显示参考图案，用户触发初始化，相机执行搜索；随后界面切换到方位显示。
4. **声音引导观察**：手机作为现场声源，改变手机位置，控制台更新方位；结尾可以看到相机支架朝向变化。

视频展示当前装置的实际操作过程；技术报告第 7 章收录同一成片的装置画面和相机朝向截图。系统分工、算法和优化结果在[技术报告](../report/main.pdf)中说明，工程实现通过[源码与复现入口](reproduce.md)查阅。

成片包含介绍排版与剪辑，段落时长不作为程序初始化或跟随延迟的测量值。耗时数据保留在对应运行记录中，按各自采集条件解释。
