# 单段真实演示拍摄稿

成片使用一次连续实录，MP4 / H.264、三分钟以内、300 MB 以内。画面只保留作品、显示器和相关硬件，不出现学校及指导教师身份信息。以下为技术报告引用的拍摄安排，实际演示以成片为准。

| 时间安排 | 实际画面 | 建议讲解 |
|---|---|---|
| 0～20 秒 | 四麦阵列、PYNQ、相机及电脑全景 | 麦克风阵列固定，相机主动朝向声音方向；声音统计在可编程逻辑中完成。 |
| 20～35 秒 | 打开桌面，观察连接与服务就绪 | 桌面与板端直接通信；连接不会自动开始初始化。 |
| 35～95 秒 | 人工点击初始化，保留全段扫描和结果 | 电脑同时提供已知声音与屏幕标识；板端搜索后以静止新图和声音参考建立相对坐标。 |
| 95～155 秒 | 当前声源触发相机朝向变化及新图 | 方向与图像判断在板端完成；未通过质量条件时显示原因。 |
| 155～175 秒 | 显示本次结果和工程入口 | 这是当前安装下的一次实际演示，完整代码、整数参考与实现报告已公开。 |

以实际完成时间为准。出现拒绝时保留完整过程与原因；重新录制需要独立开始一次完整演示。说明中将 0.021 度称为同一固定声源两段输出之差，不能称为绝对定位精度。无需加入该数值也能完整介绍作品。
