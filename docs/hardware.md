# 硬件与连接

本次开发板为 **PYNQ-Z2 / XC7Z020-CLG400-1**。已有 PCB 提供 MIC01/05/07/08，接口按物理针号记录。机构的固定安装范围为程序配置的一部分，移装后需要重新确认。

| 组件 | 作用 | 接口 |
|---|---|---|
| PYNQ-Z2 | PL 采集与相关、PS 定位和视觉、任务管理 | 以太网连接电脑 |
| MIC01/05/07/08 | 四路固定阵列输入 | 40 针连接器 I2S |
| USB UVC 相机 | 初始化标识和当前视野 | PYNQ USB host |
| ST3215 12 V 版 + UART 扩展板 | 相机朝向执行 | PMODB，扩展板 A/UART 模式 |
| Windows 电脑 | 已知宽带声、屏幕标识、桌面观察 | 有线网卡与本机扬声器 |

## 麦克风接口

连接依据包内 XDC 与 PYNQ-Z2 官方资料。信号为 3.3 V 逻辑；表中是连接器物理针号。

| 信号 | 40 针物理位置 | FPGA 球位 |
|---|---:|---|
| BCLK | 33 | W8 |
| WS | 35 | Y8 |
| SD0 | 36 | B19 |
| SD1 | 37 | W9 |
| SD2 | 38 | A20 |
| SD3 | 40 | Y9 |

时隙选择、麦克风标号与 PCB 坐标由源码和坐标 CSV 一同保留。不能根据一张拍摄照片反推针脚或调方向参数。

## 相机执行机构

PMODB1（W14，TX）连接扩展板 RX，PMODB2（Y14，RX）连接扩展板 TX，共地。扩展板采用已确认的 12 V 外部供电，控制输入使用 UART 模式；USB host 留给相机。线色不作为接口定义。

本安装的软件固定范围为 [-1321, 2775]，中心 727；速度 1800、加速度 20、RAM 参数 500。保护条件包括 10.5～12.6 V、55 °C 和电流 raw 100。上述数值属于现有安装参数，不应原样用于机械范围不同的装置。

## 网络

现有程序使用板端 `192.168.2.99`、电脑有线接口 `192.168.2.1`。板端管理入口为 8764、定位服务为 8765、状态图像入口为 8770；桌面本地入口为 `127.0.0.1:8800`。桌面启动会请求板端服务就绪，人工初始化才开始声音与视觉对齐。

辅助输出驱动源码和组合 RTL 随工程保留；本次公开操作流程使用电脑扬声器。该模块实际接法和响停验证没有纳入本次公开演示结论。
