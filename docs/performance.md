## 同输入、同功能的软件组件对照

在同一板端环境，用三份保存的 PCM、两轮交叉顺序运行原实现与缓存索引实现，共六组配对。每一组完整决策对象逐字段相等，包含拒绝原因与各子窗结果。历史语音 PCM 只参与离线计时，没有重新播放。

| 输入 / 轮次 | 原实现 / 秒 | 缓存实现 / 秒 | 决策字段 |

| background_fresh / 1 | 1.381441 | 1.238395 | 一致 |
| speech_1 / 1 | 1.357756 | 1.298175 | 一致 |
| speech_2 / 1 | 1.336231 | 1.215006 | 一致 |
| background_fresh / 2 | 1.355904 | 1.240779 | 一致 |
| speech_1 / 2 | 1.351866 | 1.180820 | 一致 |

原实现均值 1.351902 秒，缓存实现均值 1.227448 秒，本批均值下降 9.21%。样本为六组，结果说明该相位计算组件的索引缓存作用；不据此推算整机提速，也没有作为 PL 相对纯 CPU 的加速倍数。

100 MHz 布线后 setup slack +0.287 ns、hold slack +0.035 ns，66 项实现审查通过。早期 FIR 组合路径曾得到 -0.663 ns、TNS -489.416 ns、2017 个 setup 失败端点。之后采用寄存流水并验证提交生命周期。期间增加了子窗统计，因此这两次整体资源不构成单变量面积对照；正时序不能代替实物定位准确性。

## 当前初始化耗时

保存的六次成功初始化范围为 39.062～46.405 秒，中位数 43.704 秒。耗时包含服务外层、清理与持久化，原先提出的短时目标没有被当作已经达到。当前按用户确认的版本冻结。

一次 39.062434 秒成功记录的里程碑分解见性能 JSON。里程碑区间包含并行工序，不等同各线程独占 CPU 时间。音频与扫描存在事务区间重叠；没有硬件曝光时戳，不声称样本与每帧曝光严格同步。
