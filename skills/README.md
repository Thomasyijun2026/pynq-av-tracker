# 可复用技能包

| 技能 | 适用场景 | 本项目验证案例 |
|---|---|---|
| [PL 整数参考与生命周期](integer_reference/SKILL.md) | 新 RTL 算法或统计 ABI | 202+808 统计、6+24 峰值与 guard 的精确比较 |
| [PYNQ 资源与请求管理](pynq_lifecycle/SKILL.md) | DMA、相机、串口和服务协同 | 同 boot 身份、请求持久化、完成与清理记录 |
| [可复现工程交付](reproducible_delivery/SKILL.md) | 公共源码、构建及材料打包 | 独立目录恢复、原文件 SHA、RAR 解压复核 |

这些技能以本工程的已验证流程为例，不包含“任意硬件均已验证”的承诺。使用时先核对目标板卡、版本和资源拥有者。
